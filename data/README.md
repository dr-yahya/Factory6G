# Factory6G Dataset Documentation

This folder contains pre-generated datasets used for channel analysis and resource-manager training in this project.

## Files

| File | Size (bytes) | Description |
|---|---:|---|
| `factory_dataset_1k.h5` | 51,428,096 | Full ray-tracing channel dataset (complex path coefficients, delays, receiver positions). |
| `factory_dataset_1k.csv` | 310,035 | Flattened summary of the H5 data (receiver position + top-10 strongest paths). |
| `rm_training_data_sionna_1k.parquet` | 5,672,168 | Supervised training dataset for the CNN resource manager (features + oracle labels/metrics). |

## Dataset Lineage

- `factory_dataset_1k.h5` and `factory_dataset_1k.csv` are generated together by `scripts/generate_factory_dataset.py`.
- `rm_training_data_sionna_1k.parquet` is generated by `scripts/generate_dataset.py` (runtime simulation/oracle search pipeline), and is not a direct conversion of the H5/CSV file.

## Which File Is Used For What

- Channel estimator training: use `factory_dataset_1k.h5` (reads `paths_a` and `paths_tau`).
- Resource manager training: use `rm_training_data_sionna_1k.parquet` (reads `channel_energy`, `active_ut_mask`, `per_ut_power`).
- `factory_dataset_1k.csv` is a flattened summary/export for inspection and analysis, not the primary training input for those two trainers.

## `factory_dataset_1k.h5`

### HDF5 Root Attributes

- `frequency`: `3500000000.0` (Hz)

### Datasets

| Name | Shape | Dtype | Meaning |
|---|---|---|---|
| `rx_positions` | `(1000, 3)` | `float64` | Receiver (UT) position per sample: `[x, y, z]` in meters. |
| `paths_a` | `(1000, 1, 1, 128, 50, 1)` | `complex64` | Path complex coefficients (`a`) from Sionna RT CIR output, padded/truncated to `max_paths=50`. |
| `paths_tau` | `(1000, 1, 50)` | `float32` | Path delays (`tau`) in seconds, padded/truncated to `max_paths=50`. |

### Notes

- `paths_tau < 0` marks padded/invalid paths.
- In this file, `314` delay entries are padded (`-1`) out of `50,000` total path-delay entries.

## `factory_dataset_1k.csv`

Flattened summary file exported from the same generation run as the H5 file.

### Row/Column Count

- Rows: `1000`
- Columns: `24`

### Columns

- `sample_id`
- `pos_x`, `pos_y`, `pos_z`
- `path_0_mag`, `path_0_delay`
- `path_1_mag`, `path_1_delay`
- `...`
- `path_9_mag`, `path_9_delay`

### Semantics

- Position columns are in meters.
- `path_k_mag` is the magnitude of the `k`-th strongest path (descending by magnitude).
- `path_k_delay` is the corresponding path delay in seconds.

### Observed Ranges (current file)

- `pos_x`: `[-11.4908, 11.4706]`
- `pos_y`: `[-11.4769, 11.4825]`
- `pos_z`: always `1.0`
- No invalid (`<0`) delays appear in top-10 CSV path delays.

## `rm_training_data_sionna_1k.parquet`

Parquet metadata indicates creation with:

- `pyarrow 23.0.0`
- `pandas 2.3.3`

### Columns and Logical Types

| Column | Pandas Type | Meaning |
|---|---|---|
| `scenario` | `unicode` | Channel scenario label (e.g., `umi`). |
| `ebno_db` | `float64` | Eb/No used for the sample (dB). |
| `sample_index` | `int64` | Sample identifier from generation loop. |
| `channel_energy` | `list[list[float64]]` | Input feature tensor per sample (`[num_ut, fft_size]`). |
| `active_ut_mask` | `list[int64]` | Oracle-selected scheduling mask (`0/1` per UT). |
| `per_ut_power` | `list[float64]` | Oracle-selected per-UT power allocation. |
| `oracle_utility` | `float64` | Objective score used for candidate selection. |
| `oracle_avg_ber` | `float64` | BER of selected candidate. |
| `oracle_throughput_eff` | `float64` | Throughput efficiency proxy (`1 - BER`). |
| `oracle_latency_ms` | `float64` | Estimated latency in milliseconds. |
| `oracle_candidates` | `int64` | Number of candidate allocations evaluated per sample. |

### Expected Shapes (from generator/config)

- `channel_energy`: `[num_ut, fft_size]` (default config: `[8, 512]`)
- `active_ut_mask`: length `num_ut` (default `8`)
- `per_ut_power`: length `num_ut` (default `8`)

## Reproducibility

### Generate factory channel dataset (H5 + CSV)

```bash
python scripts/generate_factory_dataset.py --num_samples 1000 --output_filename factory_dataset_1k.h5
```

### Generate RM training parquet

```bash
python scripts/generate_dataset.py --output data/rm_training_data_sionna_1k.parquet --samples 1000 --batch-size 1 --scenario umi --min-ebno 0 --max-ebno 20 --seed 42 --tries 16
```

## Minimal Loading Examples

### CSV

```python
import csv
with open("data/factory_dataset_1k.csv", newline="") as f:
    rows = list(csv.DictReader(f))
print(len(rows), rows[0].keys())
```

### HDF5

```python
import h5py
with h5py.File("data/factory_dataset_1k.h5", "r") as f:
    print(f.attrs["frequency"])
    print(f["rx_positions"].shape, f["paths_a"].shape, f["paths_tau"].shape)
```

### Parquet

```python
import pandas as pd
df = pd.read_parquet("data/rm_training_data_sionna_1k.parquet")
print(df.columns.tolist(), df.shape)
```
