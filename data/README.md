# Factory6G Dataset Documentation

This folder contains the channel and training datasets used by the supported Factory6G pipelines.

## Supported Pipelines

- Channel estimator training uses `factory_dataset_*.h5`, generated by `scripts/generate_factory_dataset.py`.
- Resource-manager training uses `rm_training_data_*.parquet`, generated by `scripts/generate_dataset.py`.
- Resource-manager model training uses `scripts/train_resource_manager.py`.

The old prototype scripts for alternate RM dataset generation and alternate CNN training were removed during the correctness refactor.

## Config Schema

All supported scripts now read the refactored top-level config schema:

- `simulation`
- `monte_carlo`
- `estimators`
- `resource_managers`
- `system`
- `transceiver`
- `factory_scenario`
- `ray_tracing`

The old `system_params`, `scenario_params`, `resource_manager_params`, `transceiver_params`, and `ray_tracing_params` sections are no longer used.

## Files

| File | Description |
|---|---|
| `factory_dataset_1k.h5` | Full ray-tracing channel dataset with CIR path coefficients, delays, and receiver positions. |
| `factory_dataset_1k.csv` | Flattened summary of the H5 dataset for inspection and analysis. |
| `rm_training_data_sionna_1k.parquet` | Supervised RM training dataset produced from the runtime simulation/oracle-search pipeline. |

## `factory_dataset_*.h5`

Expected root datasets:

- `rx_positions`
- `paths_a`
- `paths_tau`

Expected root attributes:

- `frequency`

## `rm_training_data_*.parquet`

Expected columns:

- `scenario`
- `ebno_db`
- `sample_index`
- `channel_energy`
- `active_ut_mask`
- `per_ut_power`
- `oracle_utility`
- `oracle_avg_ber`
- `oracle_throughput_eff`
- `oracle_latency_ms`
- `oracle_candidates`

Expected logical shapes:

- `channel_energy`: `[num_ut, fft_size]`
- `active_ut_mask`: length `num_ut`
- `per_ut_power`: length `num_ut`

## Reproducibility

Generate the factory channel dataset:

```bash
python scripts/generate_factory_dataset.py --num_samples 1000 --output_filename factory_dataset_1k.h5
```

Generate the RM training parquet:

```bash
python scripts/generate_dataset.py --config config.json --output data/rm_training_data_sionna_1k.parquet --samples 1000 --batch-size 1 --scenario umi --min-ebno 0 --max-ebno 20 --seed 42 --tries 16 --latency-weight 0.002
```

Train the RM CNN:

```bash
python scripts/train_resource_manager.py --config config.json --data data/rm_training_data_sionna_1k.parquet --output models/cnn_resource_manager_1k.h5
```
